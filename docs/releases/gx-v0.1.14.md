# Shaiya GX gx-v0.1.14

Changes since gx-v0.1.13.

- **Parties, raids and markets.** Raid leaders can manage up to 150 members. Group loot and Perfect Party experience follow the new server rules. Players can sell stacks through personal markets with durable inventory and gold transfers. Guild houses now apply their shop, travel and gem-linking rates.
- **Combat and quests.** Update damage, accuracy and critical formulas, periodic heals and resource drains. Add Transformation, Disguise, Evolution and Soul Burn. Expand quest start conditions, objectives and timers. Fix mounted casting, small movement corrections and shortcut cooldown displays.
- **Client rendering and interface.** Batch static geometry, terrain, crowds and effects. Restore VANI alpha passes, NPC conversations, blacksmith menus and guild panels. Add local chat protection.
- **GX Server and Studio.** Edit game catalogs through the native files and SQLite as appropriate. The distributed development seed has schema migration 31 and retains the existing test accounts and inventory.
- **Downloads.** The native Windows and Linux archives include GX Studio, the terminal GX Server, fonts and server resources. Setup and upgrade instructions are maintained in the repository.

Use matching gx-v0.1.14 loose client data. The existing Google Drive download contains the full gx-v0.1.13 package. GitHub hosts the gx-v0.1.14 binaries and server data.
